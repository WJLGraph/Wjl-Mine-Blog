# Universal PPT · 全场景演示文稿蒸馏技能

> **Universal Presentation Generation** — 六类场景 × 30+ 风格 × 8 条渲染路径的 AI Agent 演示文稿技能。
>
> 一个开源 AI Agent 技能（Skill）：蒸馏 17 个开源 PPT skill 的精华，把「做一份好 PPT」从一次性手工活变成 agent 可稳定复现的工程系统 —— 先讲清，再做好，最后把好质检关。

- 仓库：<https://github.com/WJLGraph/universal-ppt-skills>
- 技能名：`universal-ppt-skill` · 蒸馏自 17 个开源 skill

---

## 一、为什么做这个

AI agent 做 PPT 的默认产出往往是这样：拿到一句话直接开生成、标题写成「研究背景」「项目介绍」式空话、高饱和配色 + 标题彩色装饰线 + 横贯色条的「AI 生成味」、该用原生 PPTX 的场合交了一份图片、做完无人质检 —— 技术正确，交付廉价。

**Universal PPT 解决的问题**：把「做一份好 PPT」的全部关键决策压缩为 agent 可稳定复现的条款 —

1. **三条不可动摇的原则**：两阶段铁律（先大纲确认再渲染，绝不一步生成）、叙事优先于排版（argument → data → layout → aesthetics）、零编造（结论可溯源，无法溯源就标注「需人工核实」）；
2. **场景路由**：先判定学术 / 商务 / 教学 / 日常 / 政务 / 竞赛哪类模式，再按模式选叙事骨架与视觉基调；
3. **两条大纲门禁**：action title 必须是完整结论句；ghost deck 测试 —— 只读全部标题串必须能独立讲出完整论证；
4. **三道质检闸**：内容 → 视觉 → 溯源，逐项 checklist + 严重度分级，不通过不交付。

## 三、六类场景路由

| 模式 | 触发场景 | 叙事骨架 | 视觉基调 |
| --- | --- | --- | --- |
| **A 学术论证** | 文献汇报、组会、开题 / 中期 / 结题、答辩、基金申报 | 问题→方法→证据→贡献→局限 | 学术克制：白底、单字族、≤3 色 |
| **B 商务汇报** | 述职、工作总结、KPI、复盘、产品发布、招商 | 结论先行（BLUF）→论据→行动项 | 清爽专业 / 麦肯锡 / 仪表盘 |
| **C 教学讲解** | 课程、培训、科普、论文转课程、知识分享 | 认知负荷递进：是什么→为什么→怎么用→练一练 | 大字号、图示化、课件 / 白板风 |
| **D 日常表达** | 活动策划、旅行分享、纪念相册、读书会 | 情感叙事：时间线 / 主题串烧 | 自由视觉风，允许高表现力 |
| **E 政务 / 党建** | 机关汇报、专题学习、政策宣讲、年度总结 | 总体情况→主要做法→成效数据→问题不足→下步打算 | 党政红：正红 + 金白、庄重对称 |
| **F 竞赛路演** | 互联网+、挑战杯、大创、创新创业大赛 | 痛点→方案→壁垒→市场→商业模式→团队→规划 | gradient-modern / 冲击力优先 |

**判定有歧义时默认 A（学术）**；学术模式再按素材类型细分五条论证弧线（发现 / 方法 / 资源 / 实验 / 综述）。

## 四、五阶段工作流

1. **Stage 1 素材拆解**：按素材类型（论文 / 文章 / 一句话需求 / 已有 PPT）结构化提取，边读边建术语台账，全部页面逐字一致；
2. **Stage 2 大纲设计**：页面级大纲（action title + 页面类型 + 视觉建议），过 action title 门禁与 ghost deck 测试，**经用户确认后**才进入渲染；
3. **Stage 3 视觉系统**：先从风格库选风格（给 2-3 个候选 + 推荐理由），再定视觉规格 —— 单主色承担 60-70% 视觉权重、单一字族、统一网格、一页一个焦点；
4. **Stage 4 多路渲染**：按决策树在八条路径中选路（可组合），宿主已有官方 PPT 技能时文件层操作可委托；
5. **Stage 5 质检交付**：三道质检闸 + 每页 80-120 字中文讲稿 + 变更 / 复用说明。

## 五、八条渲染路径

| 路径 | 一句话 | 何时选 |
| --- | --- | --- |
| R1 代码生成原生 PPTX | pptxgenjs / python-pptx 逐页构建 | 需要可编辑、原生图表、正式交付 |
| R2 模板母版注入 | 读取模板 layouts + placeholders 按版式填充 | 有学校 / 企业统一模板硬约束 |
| R3 HTML→截图→PPTX | HTML/CSS 排版后整页截图组装 | 追求视觉自由度、零生图依赖 |
| R4 AI 生图整页 | 任意生图模型逐页出图（参考图链保持一致） | 冲击力优先、接受图片式 PPT |
| R5 Markdown 幻灯片 | Marp / Reveal.js / Slidev | 开发者向、在线演示、极快速 |
| R6 LaTeX Beamer | 公式密集的学术报告 | 数学 / 理论场合、严谨排版 |
| R7 SVG/Mermaid 矢量图 | 生成示意图 / 流程图再嵌入 | 方法框架图、架构图、关系图 |
| R8 图片→可编辑 PPTX | 图片式 PPT / 扫描页还原为原生对象 | 输入是图片，要求可编辑 |

## 六、风格库（30+）

三族风格规范 + 经典配色板，全部给出精确色值与字体对：

- **学术克制族**：深藏蓝 `1F4E79` + 中蓝 `2E75B6` + 白底为默认；白底黑字极简、单色强调等按场合选择；
- **中文实用族**（蒸馏自 codex-ppt 风格库）：汇报 / 述职 / 课件等中文场景的实用规范；
- **现代表现族**（蒸馏自 deer-flow，适配 R3/R4 路径）：gradient-modern、dark-premium 等高表现力风格；
- **经典配色板**（蒸馏自 anthropics/pptx）：R1/R2 路径直接可用的成套配色。

风格工程化规则同样内置：用户品牌色 / 学校模板色永远优先、全 deck 单一风格禁止混搭、每页信息密度交替（密→疏→密）、连续高密度页之间插喘息页。

## 七、三道质检闸

1. **内容质检**：文字截断、术语一致性、遗留占位符、引用完整性逐页过；
2. **视觉质检**：渲染为图片逐页检查，按「文字溢出 → 元素重叠 → 对齐 → 边距 → 对比度」优先级修复 —— 第一版几乎必有溢出，修一版复检一版，两遍干净即停；
3. **溯源质检**：学术 / 数据类 deck 关键结论逐一核对素材出处，引用格式统一（GB/T 7714 / APA / IEEE 按需）。

## 八、快速参考：12 页学术文献汇报标准结构

1 标题页 · 2 研究背景 · 3 科学问题与动机 · 4 相关工作与现有方法不足 · 5 核心思想 · 6 方法框架 · 7 实验设计 · 8 关键结果① · 9 关键结果② · 10 消融 / 深入分析 · 11 创新点与贡献 · 12 不足、启发与讨论

**时长换算**：讲授型约 1-1.5 分钟/页（10 分钟 ≈ 8-12 页）；答辩型 1 分钟/页；路演型可 40 秒/页。开题 / 中期 / 结题 / 竞赛 / 政务等高频场景的结构模板见 `references/narrative-patterns.md`。

## 九、安装使用

```bash
# 克隆到 agent 的 skills 目录（以 Claude Code 为例）
git clone https://github.com/WJLGraph/universal-ppt-skills ~/.claude/skills/universal-ppt-skill
```

之后对 agent 说「做一份答辩 PPT」「把这篇论文转成 slides」「述职汇报」等触发词即自动路由。技能不绑定单一模型或宿主环境 —— 渲染路径按宿主能力自适应，已有官方 PPT 技能时规格与质检仍由本技能把关。
