## 1. 项目概述

重庆市地处四川盆地东部，地形以丘陵、山地为主，气候湿润多雾，生态环境复杂多变。在全球气候变化背景下，该地区频发的极端高温干旱天气导致森林火险等级升高，植被生长受胁迫程度加剧。

传统的生态要素预测往往依赖单一统计模型或物理模型，难以同时应对火点数据的稀疏突发性与 NDVI 数据的强季节性特征。本项目提出了分而治之的建模框架：

- **火点（Fire Point）**：采用 **KNN 多输出回归 + 状态空间重构** 算法，通过捕捉历史高维状态空间的拓扑结构实现对突发火情的非参数化推演，测试集 **R² = 0.971**
- **NDVI 植被指数**：采用 **"气候态分解 + 线性自回归（Climatology-AR）"** 混合模型，有效剥离确定性季节背景与随机性气候异常，测试集 **R² = 0.801**
- **气象要素**：采用 **Attention-LSTM** 深度学习模型预测未来气温、湿度、气压等气象趋势

平台集成上述多模型预测结果，结合**火险预报指数（FE）**综合评估体系，为防火部门提供科学、准确的火灾风险评估依据。

## 4. 数据说明

### 4.1 数据来源与规格

| 数据类型 | 来源 | 空间分辨率 | 时间分辨率 | 数值范围 | 用途 |
|---------|------|-----------|-----------|---------|------|
| **火点（Fire）** | 卫星遥感反演 | ~1km（452×461 栅格） | 月度（2013-2021） | 0-100（置信度） | 火情监测与预测 |
| **NDVI** | MODIS MOD13A3 | 1km | 月度（2013-2021） | [-1, 1] | 植被健康评估 |
| **气象站点数据** | 重庆市气象局 | 站点级（38个站点） | 日值（2013-2021） | 多种要素 | 火险指数计算 |
| **地理边界** | 国家基础地理信息中心 | 区县级 | 静态 | 矢量多边形 | 空间裁剪与制图 |

### 4.2 气象数据要素

气象站点原始数据包含以下字段：

| 字段名 | 说明 | 用途 |
|-------|------|------|
| 日期 | 观测日期 | 时间序列索引 |
| 站名 | 站点名称 | 分站建模 |
| 平均气温 / 最高气温 / 最低气温 | 温度指标（℃） | FE 指数的 TE 项 |
| 平均相对湿度 / 最小相对湿度 | 湿度指标（%） | FE 指数的 HE 项 |
| 平均气压 / 最高本站气压 | 气压指标（hPa） | 辅助分析 |
| 平均2分钟风速 / 极大风速 | 风速指标（m/s） | FE 指数的 WE 项 |
| 20-20时降水量 | 日降水量（mm） | FE 指数的 YRE 项 |

### 4.3 数据预处理流程

```
原始数据
  │
  ├─ 气象数据：数据清洗 → 缺失值填补 → 按站点分割 → 8:1:1 训练/验证/测试划分
  │
  ├─ 火点栅格：投影转换 → 边界裁剪 → 重采样 → 置信度分级
  │
  └─ NDVI 栅格：辐射定标 → 大气校正 → 云雾滤波 → 边界裁剪 → 时空对齐
```

## 5. 模型设计

本项目采用**双层建模架构**——模型一处理站点级气象时序数据，模型二处理栅格级空间分布数据，两层结果最终汇聚于 FE 指数火险评估体系。

### 5.1 模型一：气象站点级预测（Attention-LSTM）

用于预测未来气象要素（气温、湿度、降水等）趋势，为火险指数计算提供输入。

**架构**：在标准 LSTM 基础上融入 **Attention 注意力机制**，使模型能够自动聚焦于序列中关键时间步的信息：

```
输入序列 → LSTM 编码 → Attention 加权 → 全连接层 → 气象要素预测值
```

**训练配置**：
- 历史数据窗口：2013年1月 ~ 2021年9月（训练集）
- 预测范围：2021年10月 ~ 2021年12月（测试集）
- 训练轮次：100 epochs，Adam 优化器，学习率 0.01
- 损失函数：MSE（均方误差）

### 5.2 模型二：栅格空间级预测

#### 5.2.1 火点预测——KNN 状态空间重构

将每月的火点栅格展平为高维向量，构建"历史状态空间"，用 KNN 回归推演未来状态。

- **训练集**：2013-2020 年月度火点栅格（共约 89 个月）
- **测试集**：2021 年 1-8 月数据
- **预测对象**：2021 年 9-12 月
- **K 值**：K=5（取 5 个最近邻的均值作为预测）
- **递归策略**：多步超前预测，通过非负约束 max(0, x) 控制误差累积

#### 5.2.2 NDVI 预测——气候态-AR 混合模型

将 NDVI 时间序列分解为气候态基准（多年同期均值）和距平分量（AR 自回归）：

- **气候态基准**：计算每月在历史年份中的平均 NDVI 值，捕捉确定性季节规律
- **距平 AR 模型**：对（实测值 - 气候态基准）的距平序列建立线性自回归：
  - 滞后项：t-1, t-2（短期记忆）, t-12（年际记忆）
  - 参数估计：最小二乘法（OLS）

## 6. 核心算法详解

### 6.1 火险预报指数（FE）

FE 指数综合五个分项指数：

```
FE = TE + HE + NRE + WE - YRE
```

| 分项 | 含义 | 数据来源 | 取值范围 |
|------|------|---------|---------|
| TE | 日最高温度火险指数 | 最高气温 | 0-20 |
| HE | 14时相对湿度火险指数 | 平均相对湿度 | 0-16 |
| NRE | 连续无降水日数火险指数 | 降水数据累计 | 0-50 |
| WE | 当日风力火险指数 | 平均风速 | 5-40 |
| YRE | 当日降水量火险指数 | 降水量 | 20-40 |

**火险等级划分**：

| FE 范围 | 等级 | 名称 | 颜色标识 |
|---------|------|------|---------|
| ≤20 | 1级 | 无火险 | 绿色 |
| 21-40 | 2级 | 低度火险 | 黄色 |
| 41-60 | 3级 | 中度火险 | 橙色 |
| 61-80 | 4级 | 高度火险 | 红色 |
| ≥81 | 5级 | 极度火险 | 紫色 |

### 6.2 KNN 状态空间重构（火点）

将火点分布矩阵 $M_t \in \mathbb{R}^{H \times W}$ 展平为向量 $\mathbf{x}_t \in \mathbb{R}^D$，在 $D$ 维欧氏空间中寻找 $K$ 个最近邻居：

$$
\hat{\mathbf{x}}_{next} = \frac{1}{K} \sum_{j \in \mathcal{N}_K} \mathbf{x}_{i_j+1}
$$

物理约束（非负性）：

$$
\mathcal{P}(\mathbf{x}) = \max(\mathbf{0}, \mathbf{x})
$$

### 6.3 气候态-AR 混合模型（NDVI）

**分解**：

$$
Y_t = C_{m(t)} + A_t
$$

- $C_{m(t)}$：月份 $m(t)$ 的气候态基准（历史同期均值）
- $A_t = Y_t - C_{m(t)}$：距平分量

**AR 预测**：

$$
\hat{A}_t = \beta_0 + \beta_1 A_{t-1} + \beta_2 A_{t-2} + \beta_{12} A_{t-12} + \epsilon_t
$$

## 10. 实验结果

### 10.1 火点 KNN 预测

| 指标 | 训练集 | 测试集 |
|------|-------|-------|
| MSE | ~0 | ~0.001 |
| MAE | ~0 | ~0.005 |
| **R²** | **0.982** | **0.971** |

由于火点数据的高度稀疏性（大部分栅格值为 0），模型能够极好地预测"无火"背景，同时对主要火点聚集区有较好的命中率。

### 10.2 NDVI 气候态-AR 混合预测

| 模型 | 训练集 R² | 测试集 R² |
|------|----------|-----------|
| 仅气候态基准 | N/A | 0.787 |
| KNN-Anomaly（对比） | 1.000 | 0.764 |
| **Climatology-AR 混合** | **0.815** | **0.801** |

气候态基准解释了约 79% 的 NDVI 变异；引入 AR 模型后精度提升约 1.4%，代表了模型对"气候异常"的预测能力。

### 10.3 Attention-LSTM 气象预测

通过融合注意力机制，LSTM 模型能够自适应地聚焦于历史序列中的关键时间步（如极端高温/干旱事件），提升了对气象异常的捕捉能力。万州站 2021 年 10-12 月气温和湿度预测与实际值整体趋势吻合良好。

## 11. 系统界面展示

### 11.1 登录界面
简洁的用户名/密码认证界面，支持管理员与普通用户区分。

### 11.2 数据上传与分析界面
上传 CSV 数据后自动生成：
- 每年火点数量柱状图
- 每年逐月火点趋势折线图
- 不同置信度火点堆叠柱状图
- 火灾发生趋势 2 年移动平均图
- 火点空间分布交互地图

### 11.3 空间分析界面
按年份和月份筛选，生成带区县边界标注的火点空间分布图。

### 11.4 模型预测界面
- **火点 KNN**：显示 MSE/MAE/R² 指标，输出预测栅格并支持下载
- **NDVI KNN**：显示训练/测试集指标，输出 NDVI 预测栅格
- **LSTM 分析**：多站点多要素预测折线图（历史值 vs 预测值）

### 11.5 火险等级分布图
基于 FE 指数公式计算各站点火险等级，在地图上用绿/黄/橙/红/紫五色标识区县火险等级。
