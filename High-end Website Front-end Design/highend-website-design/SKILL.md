# High-end Website Front-end Design（高端网站前端设计）

将普通网页升级为 Awwwards 级高端展示页。核心思想：**"高级感"不是某个特效，而是一套可复制的系统 = 克制的美术方向 × 排版功底 × 节奏化动效 × 工程细节**。本技能归纳了获奖站点（及"每期拆解一个高端网站"类内容所展示案例）的共性模式库。

## 核心原则（必须遵守）

1. **先定调，再写码。** 动手前必须先从 `references/style-systems.md` 选定一个风格体系（含字体、配色、间距 token），禁止混搭多个体系。用户未指定时，默认「暗黑奢华 · Nocturne」或「瑞士极简 · Swiss Mono」。
2. **克制优于炫技。** 每页同时运行的"大型动效"（pinned、水平滚动、3D）不超过 2 处；强调色全站仅 1 个；禁止高饱和彩色色块堆砌、禁止滥用渐变与发光。分隔线优先用 0.5–1px 细线（hairline: `rgba(237,237,237,.14)` 级别的弱分隔线）。
3. **字体是第一动效。** 高端感 70% 来自排版：超大标题（clamp 到 8–12vw）、紧字距（-0.02em ~ -0.05em）、大留白、明确的字号阶梯（display / h2 / body / caption 至少 4 级，层级比 ≥ 2.5 倍）。
4. **动效必须有叙事职能。** 每个动画要么引导视线、要么揭示信息、要么建立节奏；纯装饰动画一律删除。滚动叙事遵循：Preloader 定调 → Hero 炸场 → 中段节奏起伏（密/疏交替）→ 结尾收束。
5. **单文件交付优先。** 默认产出可直接打开的单文件 HTML（CDN 引 GSAP + ScrollTrigger + Lenis + SplitType），确保能即时预览与本地部署；除非用户明确要工程化项目。
6. **降级完备。** 所有动效必须处理 `prefers-reduced-motion`、触屏无 hover、窄屏布局三重降级，参考 `references/implementation.md`。
7. **呼吸感是高端与廉价的第一分界线。** 页面要像乐章一样呼吸：密→疏→密交替，两个高密度区块之间必须插入"近空屏"（约 60–100vh 的高度内只有单行大字或纯留白）；每屏只讲一个信息点；元素入场后留出至少 0.3s 的"呼吸位"再进下一个动画。**现代简约感来自"少"，高端感来自"慢"**——缓动宁可慢 0.2s，不可急；宁可删一个动效，不可挤掉留白。

## 工作流程

按顺序执行：

### Step 1 — 需求定位（最多 1 次询问，不反复追问）
向用户确认三件事（可合并为一次提问）：
- 网站类型与内容（品牌 / 产品 / 作品集 / 数据展示）
- 情绪调性关键词（从 Step 2 的风格体系中选或自述）
- 是否有品牌资产（logo、品牌色、字体、图片素材）

用户只给模糊描述（如"做一个高级感的官网"）时：直接选定风格体系并说明理由，用占位内容先出一版，供用户基于实物迭代——不空转追问。

### Step 2 — 选定风格体系
读 `references/style-systems.md`，从 6 个体系（Nocturne 暗黑奢华 / Swiss Mono 瑞士极简 / Editorial 杂志编辑 / Technical Brutalist / Warm Humanist / Immersive 3D）中选定一个，提取其中的字体对、配色 token、间距与线宽规范，落为 CSS 变量。**不混用体系。**

### Step 3 — 页面结构规划
按高端网站通用叙事骨架规划区块（按需取舍，不是全都要）：
1. Preloader（计数 0→100 + 揭幕）
2. 固定导航（细线底边、毛玻璃或纯色，当前区块指示）
3. Hero（全屏、超大字、一次到位的入场编排）
4. Manifesto / 品牌宣言段（居中大字逐行浮现）
5. 内容主体（作品卡片 / 服务列表 / 数据展示，密疏交替）
6. Marquee 滚动条（品牌词或数据无缝滚动）
7. 大图视差段（图片 clip-path 揭示 + 视差）
8. CTA / Footer（超大联系字号 + 细线分隔的信息栅格）

### Step 4 — 动效编排
读 `references/motion-patterns.md`（12 个模式，每个含用途/时机/参数），挑选 5–8 个模式组合，并**严格遵守其末尾的《呼吸感节奏律》**（动-静交替、空屏原则、每屏一个焦点、慢即是贵）。常用黄金组合：**Preloader + Lenis 平滑滚动 + 文字逐行揭示 + 图片 clip-path 揭示 + Marquee + 自定义光标 + hairline 细线分隔**。参数一律从模板默认值起步微调，不自己发明数值。

### Step 5 — 实现
- 单文件交付：整文件复制 `assets/template.html` 为起点（已内置 Preloader、Lenis、自定义光标、磁性按钮、逐行揭示、Marquee、图片揭示、grain 颗粒、响应式与 reduced-motion 降级），替换调性 token 与内容。
- 工程化交付（用户明确要求 Vue/React 时）：遵循 `references/implementation.md` 的"工程化集成"一节（SSR/hydration 注意事项、库的封装方式、路由转场）。
- 图片：优先用户素材；无素材用 Unsplash 直链并标注可替换；`aspect-ratio` 锁定防布局抖动。

### Step 6 — 质检（交付前必过）
对照 `references/implementation.md` 末尾的《交付质检清单》逐项检查：首屏 3 秒定调、滚动节奏、触屏降级、reduced-motion、性能（无长任务卡顿、图片懒加载）、文案层级、细线与留白复查。未过清单不交付。

## 反模式（出现即返工）

- 高饱和渐变色块、紫色 Tailwind 渐变、卡片阴影堆叠、"Bootstrap 感"圆角卡片阵列
- 无 Preloader 直接蹦出内容、或 Preloader 超过 2.5 秒
- 全站到处 parallax / 到处发光 / 到处 3D
- 系统默认字体的细字重大段正文、行长超过 35em
- 动画 easing 全用 `linear` 或默认 ease（高端动效几乎只用 custom cubic-bezier：`0.65, 0, 0.35, 1` / `0.76, 0, 0.24, 1` / `expo.out`）
- 移动端没有适配就交付（断点 < 768px 必查）
