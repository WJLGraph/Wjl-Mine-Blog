# 动效模式库（Motion Patterns）

12 个高端网站通用动效模式。每个模式含：用途 / 使用时机 / 关键参数 / 降级。所有基于 GSAP v3 + ScrollTrigger + Lenis + SplitType 的写法见 `assets/template.html`，此处记录的是**选择与编排知识**。

## 通用参数约定（不要自己发明数值）

- 入场时长：0.8–1.2s；stagger 间隔：0.06–0.12s
- 揭示 easing：`power4.out`（文字/元素入场）、`expo.out`（光标/跟随类）
- clip 揭示 easing：`power3.inOut`
- 页面级转场：0.6–0.9s
- 位移距离：文字逐行揭示用 110%（保证完全离开可视区）；元素入场用 40–80px，不超过 120px
- 所有 cubic-bezier 备选：`0.65,0,0.35,1`（对称丝滑）、`0.76,0,0.24,1`（快出慢停）

## P1 — Preloader 计数揭幕

**用途**：定调 + 掩盖资源加载。**时机**：首次进入，总时长控制在 1.5–2.5s。
**结构**：全屏纯色层 → 右下角 mono 大计数 0→100 → 数字归零后整层向上滑出（`y: -100%`）或分 2–3 条横幕依次揭开 → Hero 入场动画紧接揭幕结束（错峰 0.1s，形成"揭幕即开场"）。
**参数**：计数用 `gsap.to(obj, {val: 100, duration: 1.6, ease: "power2.inOut"})` + `onUpdate` 更新文本。
**降级**：reduced-motion 下直接淡出 300ms；`sessionStorage` 记录后同会话不再播放。

## P2 — Lenis 平滑滚动

**用途**：让一切滚动动效获得"惯性丝滑"质感，是所有高端站的地基。**时机**：全站启用。
**参数**：`lerp: 0.1`（越小越丝滑）、`wheelMultiplier: 1`。**必须**与 ScrollTrigger 同步：`lenis.on('scroll', ScrollTrigger.update)` + gsap ticker 驱动。
**降级**：触屏设备不启用（原生滚动更跟手）；reduced-motion 不启用。

## P3 — 文字逐行揭示（Line Reveal）

**用途**：标题与段落的核心入场。**时机**：进入视口时。
**结构**：SplitType 按 `lines` 切分 → 每行外包 `overflow: hidden` 容器 → 内层从 `y: 110%` 到 `y: 0`，stagger 0.1s，`power4.out`。
**注意**：resize 后必须 `split.revert()` 重新切分；中文按行切分安全（按字切分中文会破坏阅读，禁用 char 模式排版正文）。

## P4 — 图片 clip-path 揭示

**用途**：图片"擦亮"式入场。**时机**：图片进入视口 70% 时。
**参数**：`clip-path: inset(100% 0 0 0)` → `inset(0% 0 0 0)`，1s，`power3.inOut`；同步内部 `img` 从 `scale(1.3)` 到 `scale(1)`（反差动效，1.2s）。
**变体**：hover 时反向微收紧 `inset(2%)`。

## P5 — Marquee 无缝滚动条

**用途**：品牌词、合作方、数据的持续律动，填充节奏空隙。**时机**：常驻。
**参数**：内容复制两份、`x: -50%` 无限 `repeat: -1`、linear、30–40s；**高配**：滚动速度与方向响应页面滚动速度（`xPercent` 乘以滚动速度系数），产生"页面滚它也滚"的联动感。
**注意**：宽度必须用内容两份保证无缝；文字要低调（fg-dim 色），不能抢主体。

## P6 — 自定义光标（Cursor）

**用途**：精致感的关键微交互。**结构**：8px 圆点（实时跟随）+ 32px 圆环（lerp 0.15 延迟跟随）。
**行为**：hover 可交互元素时圆环放大 1.5–2 倍并混合模式变反色（`mix-blend-mode: difference`）；hover 图片时圆环内显示 mono 小字（"VIEW"）。
**降级**：`@media (hover: none)` 完全隐藏，恢复原生光标。全站唯一 `mix-blend-mode` 使用点，禁止滥用。

## P7 — 磁性按钮（Magnetic）

**用途**：CTA 的"引力"手感。**参数**：鼠标进入按钮周围 80px 感应区时，按钮向鼠标位移（最大 0.3 倍距离），leave 时 `elastic.out(1, 0.4)` 回弹。
**降级**：触屏禁用。全站只给主要 CTA（≤3 处）加磁性，不能到处磁。

## P8 — Pinned 滚动叙事（ScrollTrigger pin）

**用途**：中段的"驻留讲解"：图片序列轮播、文字逐条替换。**时机**：全站最多 2 处。
**参数**：`pin: true, scrub: 1, end: "+=200%"`；内容切换用交叉淡入 + 轻微位移（20px）。
**高配变体**：水平滚动画廊（`xPercent` 驱动），注意移动端改为原生水平滑动或纵向堆叠。

## P9 — 视差（Parallax）

**用途**：分层深度。**参数**：背景层 `yPercent: -10 → 10`（scrub）；前景文字反向或不动。幅度保持小（±15% 以内），**禁止**大幅"过山车"视差。

## P10 — 无限字墙 / 文字波浪（Kinetic Type）

**用途**：Hero 或转场的大字动势：整行超大文字连续横移、或鼠标划过逐字弹起。**时机**：仅 Hero 或 CTA 段，一页一处。
**注意**：这是最容易"廉价化"的模式，文字内容必须短（≤4 词）。

## P11 — 页面转场（Page Transition）

**用途**：多页站点的换页遮幕。**参数**：点击后遮幕层（品牌色/纯黑）从下往上盖住 0.5s → 换 URL → 揭开 0.7s。
**单文件 SPA 模拟**：锚点路由 + gsap 遮幕，见模板注释段。

## P12 — Grain 颗粒质感

**用途**：全站铺一层极淡噪点，消除大面积纯色的"塑料感"，是低饱和配色的隐藏功臣。
**实现**：SVG `feTurbulence` 生成 data-URI 噪点图，`position: fixed; inset: 0; opacity: .04–.06; pointer-events: none; mix-blend-mode: overlay`。**必须** `pointer-events: none`。静态即可，动画噪点消耗性能且显乱。

## 编排原则

1. **一页一个主角动效**：Hero 承担"炸场"（P1+P3 组合），中段用 P4/P5 维持呼吸，pinned 段（P8）是唯一的高潮点，Footer 收平。
2. **密度节奏**：动效区与静区交替（动-静-动），连续两个区块都有大动效 = 返工。
3. **同时进入视口的元素统一编排**：用同一 timeline 加 stagger，不要各自为政。
4. **滚动方向语言**：入场一律从下往上（y 轴正向揭示）；横移（x 轴）只用于 Marquee 与水平画廊。

## 呼吸感节奏律（Breathing Rhythm）——最高优先级编排法则

高端网站与模板站的差距，一半在动效质量，另一半在**节奏呼吸**。以下法则优先级高于任何单个动效模式的选择：

### B1 — 动 / 静 / 动交替
页面按"乐句"组织：一个动效密集段（如作品列表连续揭示）之后，必须跟一个静止段（纯排版、无滚动触发动画、无 hover 微动的段落）。连续两个区块都带大动效 = 节奏死亡，返工。

### B2 — 空屏原则
两个高密度区块之间插入"近空屏"：约 60–100vh 的高度内，只允许单行大字（一句宣言 / 一个数据）、或纯留白 + 一枚 mono 小标签。全页至少出现 2 处近空屏。浏览者在惯性滚动中需要"能停下来喘息"的位置——这就是呼吸感的物理来源。

### B3 — 每屏一个焦点
任何一个视口范围内只允许一个视觉焦点（一张图 / 一行大字 / 一个数据）。两个焦点抢一屏 = 立即拆成两屏。检查方法：逐屏截图，每张图必须能用 ≤5 个字说出"这屏在讲什么"。

### B4 — 呼吸位
同一时间线内，两组入场动画之间保留 ≥ 0.3s 的静止间隙；一段动效结束后，至少等 0.5s 再允许下一屏动效触发。宁可让页面某一刻"什么都不发生"——静止本身就是设计。

### B5 — 慢即是贵
- 入场时长宁取区间上限：0.9–1.2s，不取 0.5s
- scrub 类动画 smoothing 取 1s（跟手但拖影感）
- Lenis `lerp: 0.1`（丝滑惯性），绝不调快
- 缓动收尾要"落得稳"：`power4.out` / `expo.out` 的长尾比快停更显贵
- 快节奏只留给光标、hover 等微交互（0.3–0.45s），页面级动画永远从容

### B6 — 滚动叙事节拍（现代滚动叙述的标准结构）
参考叙事骨架的时间轴组织，长页面每 3–5 屏安排一个"节拍点"（高潮），节拍点之间用空屏与静段过渡：

```
Preloader → Hero(炸场) → [空屏宣言] → 内容段A(节奏中) 
→ [Marquee过渡] → 内容段B(唯一高潮: pinned/大图) 
→ [空屏收] → CTA(收束) → Footer(归零)
```

现代简约感 = 每一屏的信息都少而清楚；高端感 = 所有变化都慢而有把握。两者叠加就是"呼吸感"。
